# PancakeSwap Prediction Clicker

Python-автоматизация ставок в [PancakeSwap Prediction](https://pancakeswap.finance/prediction) (BSC) через симуляцию кликов мышью. Личный эксперимент: бот сам выбирает направление по цвету графика, делает ставку, подтверждает её в MetaMask, проверяет результат и собирает выигрыш.

⚠️ **Дисклеймер.** Проект автоматизирует игру на реальные деньги и создан в образовательных целях. Используйте на свой риск — можно потерять вложенные средства.

## Как это работает

Бот не управляет браузером через API — он работает с реальным экраном:

- кликает по заданным координатам (`x,y,monitor=N`, поддерживаются мульти-мониторы и Windows DPI-awareness);
- принимает решения по цвету пикселя (график TradingView — зелёный/красный, кнопка Collect — активна/нет);
- баланс BNB читает по RPC через web3, адрес кошелька берёт из `.env`.

## Установка и запуск

1. Требования: **Windows + Chrome + MetaMask**, Python 3.10+
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Создать `.env` из шаблона и указать адрес кошелька (используется только для чтения баланса):

```
METAMASK_BSC_ADDRESS="0x..."
```

4. Откалибровать координаты под свой экран: открыть сайт+MetaMask и перезаписать точки клика в `DASHBOARD.py` с помощью `TOOLS/save_the_click.py` (и цвета решение кнопок/графика).
5. Запустить:

```bash
python RUN.py
```

Остановка: **Ctrl+C** — первый раз скрипт завершит текущий список шагов и выполнит корректное выключение, во второй раз — принудительная остановка.

## Рекомендации

- Не двигайте мышь во время работы и не меняйте размер/расположение окон браузера — координаты рассчитаны под зафиксированный интерфейс.
- Не открывайте MetaMask в отдельной вкладке — закрытие попапа ломает подтверждение транзакций.
- Запускать только на отдельной, не используемой для другой работы машине.
